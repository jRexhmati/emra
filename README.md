# emra.coo.al

Emrat shqip me 3–6 shkronja dhe lindjet çdo vit 2016–2025, sipas kërkimit të emrave të INSTAT.

- `data.json`: rreshtat: emri, drejtshkrimi i kërkimit (nëse ndryshon), gjinia, femra, meshkuj, gjithsej, pastaj lindjet 2016..2025.
- `build.mjs`: gjeneron faqen kryesore, një faqe për çdo emër, listat e vajzave/djemve, sitemap dhe robots në `_site/`.
- GitHub Actions ndërton dhe publikon në çdo push te `main`.
